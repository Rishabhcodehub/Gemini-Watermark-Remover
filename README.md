# OmniFlash & Veo Watermark Remover (Image & Video)

[![Stack](https://img.shields.io/badge/tech-HTML%20%7C%20JS%20%7C%20WebCodecs-3B82F6?style=flat-square)](https://github.com/dearabhin/gemini-watermark-remover)
[![License](https://img.shields.io/badge/license-MIT-orange?style=flat-square)](LICENSE)

A high-performance, **100% client-side** tool for removing watermarks from **images and videos** generated by Google Gemini AI, OmniFlash, and Google Veo. Built with Vanilla JavaScript, WebCodecs, and Canvas, it uses edge-preserving anisotropic reconstruction and mathematically precise **Reverse Alpha Blending** to restore pixels with zero quality loss.

---

## 🚀 Features

* **OmniFlash & Veo Video Models:** Easily switch between OmniFlash (4-point sparkle logo) and Google Veo (text logo) video watermarks.
* **Landscape & Vertical (Portrait) Videos:** Full native support for standard landscape (16:9), portrait / vertical videos (9:16, Reels/Shorts/TikTok), and square (1:1).
* **Image & Video Support:** Seamlessly handles images (PNG, JPG, WebP) and videos (MP4, WebM, MOV).
* **Exact FPS & Frame-Accurate Extraction:** Automatically detects video frame rate (e.g. 24 fps, 30 fps, 60 fps) and extracts all frames (e.g. 10s @ 24fps = 240 frames).
* **Audio Track Preservation:** Automatically extracts, decodes, and synchronizes the original audio track back into the reassembled video.
* **100% Client-Side Processing:** No servers involved. Media files are processed locally in your browser for complete privacy.
* **Lossless Mathematical Restoration:** Uses exact alpha inversion and edge-preserving reconstruction rather than lossy AI inpainting blur.
* **Synchronized Video Preview:** Side-by-side comparison player with synchronized play/pause and scrubbing.
* **Fast Hardware Acceleration:** Utilizes native browser WebCodecs API and `mp4-muxer` for instant processing.

## 🧠 How It Works (The Algorithm)

Gemini, OmniFlash, and Veo add watermarks using standard **Alpha Compositing** (blending):

$$Pixel_{final} = (\alpha \times Pixel_{logo}) + (1 - \alpha) \times Pixel_{original}$$

### 1. Watermark Detection & Geometry
- **OmniFlash Video Watermark**: 4-pointed sparkle symbol logo (48×48 px at 720p, scaled by `min(width, height) / 720.0` to support both landscape and vertical videos) positioned with 96px margins from the right and bottom edges.
- **Google Veo Video Watermark**: Text logo (54×26 px at 720p) positioned with 20px right margin and 25px bottom margin.
- **Gemini AI Images**: Sparkle icon (48px or 96px depending on resolution) with 32px or 64px margin.

## ⚡ Running Locally

Since this project uses **ES6 Modules** (`import`/`export`), serve it via a local web server:

### Option 1: Double-Click
Run `RunApp.bat` (starts Python server on port 8000 and opens browser).

### Option 2: Python
```bash
python -m http.server 8000
```
Open `http://localhost:8000` in your browser.
